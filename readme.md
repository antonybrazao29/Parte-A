# Memória descritiva
Para este projeto foi pedido replicar com o maior rigor possível a Composição n.º III de Piet Mondrian em um canvas com largura minima de 800 px. As cores foram tiradas diretamente desde a obra disponibilizada usando o site imagecolorpicker.com. As coordenadas foram conseguidas através do processo de colocar a imagem da obra no adobe Illustrator e criar vetores em cima dos quadrados da pintura. As transições do quadrado azul e amarelo foram feitas através da função map(). para calcular os valores entre o RGB inicial e o RGB final, a textura de papel foi feita inteiramente através de uma função for, onde geram pixeis aleatórios de cinzento entre os valores da largura e altura do canvas.
